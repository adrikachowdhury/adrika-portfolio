# Adrika Chowdhury | Personal Portfolio

Welcome to my personal portfolio! This repository contains the source code for my portfolio website, where I showcase my academic background, research, projects, technical skills, and professional experience.

## Live Website

[Visit My Portfolio](https://adrikachowdhury.github.io/adrika-portfolio/)

## Website Sections

- **Home:** Introduction and overview.
- **About Me:** Academic background, experience, and skills.
- **Projects:** Selected software development, machine learning, and NLP projects.
- **Research:** Research interests, publications, and academic work.
